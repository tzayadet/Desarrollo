## Archive policy

- Do not develop new features in this repository's copied project folders.
- Make changes in the corresponding standalone repository.
- Keep each project's demo deployment scoped to its own static output.
- Never publish private source code, real candidate data, credentials, API tokens or local databases as part of a demo.
- Mark previews, simulations and incomplete applications honestly; a successful Pages build does not prove that a backend is running.
