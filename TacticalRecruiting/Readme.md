# Tactical Recruiting · Public Demo

Standalone browser demonstration of an IT recruitment workflow.

**Live demo:** pending GitHub Pages activation for the private source repository.

## What this demo shows

- Candidate pipeline with fictional sample records.
- IT role and technical-skill categorization.
- Interview and evaluation workflow examples.
- Browser-only interaction and sample data persistence.

## Architecture

The complete Python/SQLite application is maintained in the private repository [TacticalRecruiting](https://github.com/tzayadet/TacticalRecruiting).

This public folder contains only the static demonstration. It does not include the Python application, database implementation, candidate documents or internal project specification.

## Privacy and limitations

- All candidate records and email addresses are synthetic examples using reserved `example.com` addresses.
- Demo state is stored in the browser's local storage.
- There is no backend, account system, server-side persistence or connection to a real candidate database.
- Do not enter real candidate data, CVs, contact details or confidential recruitment information.
- This is a portfolio prototype, not a production ATS or a tool for automated hiring decisions.
